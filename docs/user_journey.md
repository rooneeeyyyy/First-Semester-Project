# Console User Journey

Main menu -> selected feature -> result -> return to the menu

Main menu
1. Food: show all food, search by name or category, filter by budget
2. Cafeterias: list, view a cafeteria and its menu, compare 2 or 3 cafeterias
3. Campus Map: show locations, search a location, show connections, find a route
4. Assistant: type a question in English or Roman Urdu
5. Favorites: show, add, remove
0. Exit

Rules
- An invalid choice shows an error and returns to the menu.
- Typing 0 in a sub-menu goes back. The program exits only when 0 is typed in the main menu.
- In the assistant, type back to return to the main menu.
- Location names can be partial. If several places match, the program lists them and asks for a more specific name.
