# FAST Navigator & Cafeteria Hub

A C console program for campus food search, cafeteria menus, route finding and a simple rule-based assistant.

## Team roles
- Person 1: Core and Algorithms (graph, routes, assistant)
- Person 2: Data and Backend (food, cafeterias, CSV files, favorites)
- Person 3: Interface and Delivery (menu, validation, documentation, demo)

## Build and run
From the project root:

    gcc -Wall -Wextra -Iinclude src/main.c src/ui.c src/map.c src/food.c -o fast_navigator
    .\fast_navigator.exe
